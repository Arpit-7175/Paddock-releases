# Screenshots

Drop six PNGs here, named exactly as below — the table in the root README points at these paths:

| File                  | Screen to capture                                              |
|-----------------------|----------------------------------------------------------------|
| `for-you.png`         | For You tab (the feed of rides/routes near you)                |
| `ride-details.png`    | A ride's detail page — one with a real route drawn on the map  |
| `live-tracking.png`   | Live tracking during a ride, with rider pins on the map        |
| `ride-chat.png`       | A ride chat with a few messages, ideally a photo and a reply   |
| `groups.png`          | A club/group page, or the groups list                          |
| `profile.png`         | A rider profile with a bike in the garage and some posts       |

Capture on the phone (power + volume-down), then pull them across. Portrait, no
notification-shade clutter, and a ride with a real route in it looks far better
than an empty state.
